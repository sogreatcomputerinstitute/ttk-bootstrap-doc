Welcome to TTKBootstrap - Modern Python GUI Framework

TTKBootstrap is a modern, responsive theming library for Python's Tkinter that revolutionizes how you create desktop applications. It brings the beauty and functionality of Bootstrap styling to Tkinter widgets, enabling developers to build professional-looking GUI applications without extensive design knowledge. Whether you're a beginner learning Python or an experienced developer building enterprise applications, TTKBootstrap provides the tools you need to create stunning user interfaces.

Instead of spending hours styling individual widgets or learning complex CSS-like syntax, TTKBootstrap gives you immediate access to pre-designed, professionally crafted themes that work across all your widgets. Create beautiful applications in less time, with less code, and without sacrificing customization.

Installation & Quick Start Guide

Getting started with TTKBootstrap is incredibly simple. Follow these three straightforward steps to begin building beautiful Python GUI applications. The installation process takes less than a minute, and you'll be ready to create professional applications immediately.

1

Install Package

Install TTKBootstrap using pip package manager

pip install ttkbootstrap
2

Import Library

Import TTKBootstrap in your Python script

import ttkbootstrap as ttk
3

Create Application

Create your first TTKBootstrap application

root = ttk.Window(themename="darkly") root.mainloop()

Getting Started Example

Here's a simple complete example to get you started:

import ttkbootstrap as ttk from ttkbootstrap.constants import * # Create the main window root = ttk.Window(themename="darkly") root.title("My TTKBootstrap App") root.geometry("400x300") # Create a label label = ttk.Label( root, text="Welcome to TTKBootstrap!", font=("Helvetica", 14) ) label.pack(pady=20) # Create a button def on_click(): print("Button clicked!") button = ttk.Button( root, text="Click Me!", command=on_click ) button.pack(pady=10) # Run the application root.mainloop()

Themes: Styling Your Application

What Are Themes?

Themes are pre-designed color schemes and styling templates that instantly transform the appearance of your application. Instead of manually defining colors, fonts, and styles for every widget, TTKBootstrap themes provide professionally designed combinations that work together harmoniously. Each theme has a specific aesthetic and is suited for different types of applications.

Key Benefits:

  • ⏱️ Save Time: Apply complete styling with one line of code
  • 🎨 Professional Appearance: Designs created by professionals
  • 🔄 Easy Switching: Change themes at runtime with no code changes
  • 📱 Consistent Styling: All widgets match the theme automatically
  • ♿ Accessibility: Themes consider color contrast and readability

Available Themes & Use Cases

Darkly

Modern dark theme perfect for applications that need to reduce eye strain. Best for: Code editors, monitoring dashboards, developer tools, media applications.

Superhero

Dark blue professional theme with vibrant accents. Best for: Enterprise applications, data analysis tools, professional software, SaaS platforms.

Flatly

Minimal light theme with flat design. Best for: Educational apps, productivity tools, daytime usage, minimalist design preference.

Minty

Fresh mint green theme. Best for: Health apps, wellness tools, environmental applications, modern startups.

Pulse

Dark purple vibrant theme. Best for: Creative tools, gaming applications, entertainment software, modern design-focused apps.

How to Use Themes in Your Application

1. Set Theme at Startup

Choose a theme when creating your main window:

import ttkbootstrap as ttk # Create window with a specific theme root = ttk.Window( themename="darkly" # Choose your theme here ) root.title("My Application") root.mainloop()

2. Change Theme at Runtime

Let users switch themes dynamically with buttons or a dropdown:

import ttkbootstrap as ttk root = ttk.Window(themename="darkly") def change_theme(theme_name): # Switch to a different theme root.style.theme_use(theme_name) # Create a dropdown to select theme theme_var = ttk.StringVar(value="darkly") themes = ["darkly", "superhero", "flatly", "minty", "pulse"] combo = ttk.Combobox( root, values=themes, textvariable=theme_var, state="readonly" ) combo.pack(pady=10) combo.bind("<<ComboboxSelected>>", lambda e: change_theme(theme_var.get())) root.mainloop()

3. Theme Selection Guide

Choose your theme based on your application type:

Complete Theme Switching Example

Here's a full application that lets users switch between themes with a nice interface:

import ttkbootstrap as ttk class ThemeSwitcherApp: def __init__(self, root): self.root = root self.root.title("Theme Switcher") self.root.geometry("400x300") # Title ttk.Label( root, text="Choose a Theme", font=("Helvetica", 16, "bold") ).pack(pady=20) # Theme list themes = ["darkly", "superhero", "flatly", "minty", "pulse"] for theme in themes: ttk.Button( root, text=theme.capitalize(), command=lambda t=theme: self.root.style.theme_use(t), width=20 ).pack(pady=8) if __name__ == "__main__": root = ttk.Window(themename="darkly") app = ThemeSwitcherApp(root) root.mainloop()

Advanced Usage

Build a Complete Todo Application

Here's a complete example of a professional Todo app:

import ttkbootstrap as ttk from ttkbootstrap.dialogs import Messagebox class TodoApp: def __init__(self, root): self.root = root self.root.title("Todo App") self.root.geometry("500x400") # Title title = ttk.Label( root, text="My Todo App", font=("Helvetica", 16, "bold"), bootstyle="primary") title.pack(pady=20) # Input Frame input_frame = ttk.Frame(root) input_frame.pack(pady=10, padx=10) self.entry = ttk.Entry(input_frame) self.entry.pack(side="left", fill="x") ttk.Button(input_frame, text="Add", command=self.add_todo).pack(side="left") def add_todo(self): task = self.entry.get() if task: self.listbox.insert("end", task) self.entry.delete(0, "end") if __name__ == "__main__": root = ttk.Window(themename="darkly") app = TodoApp(root) root.mainloop()

Working with Data

# Using Variables to Track State username_var = ttk.StringVar() password_var = ttk.StringVar() agree_var = ttk.IntVar() username_entry = ttk.Entry( root, textvariable=username_var) password_entry = ttk.Entry( root, textvariable=password_var, show="*") agree_cb = ttk.Checkbutton( root, text="I Agree", variable=agree_var) def submit(): username = username_var.get() password = password_var.get() agreed = agree_var.get() print(f"Username: {username}, Agreed: {agreed}") submit_btn = ttk.Button( root, text="Submit", command=submit) submit_btn.pack()

Best Practices

Naming Conventions

# Good primary_button = ttk.Button(...) error_label = ttk.Label(...) # Avoid btn = ttk.Button(...) lbl = ttk.Label(...)

Organize with Frames

# Group related widgets form_frame = ttk.Frame(root) form_frame.pack(fill="x") button_frame = ttk.Frame(root) button_frame.pack(fill="x")

Use Variables

# Track state with variables var = ttk.StringVar() entry = ttk.Entry( root, textvariable=var) value = var.get()

Reusable Components

class FormField: def __init__(self, parent, label): self.var = ttk.StringVar() ttk.Label(parent, text=label).pack() ttk.Entry(parent, textvariable=self.var).pack()

Event Handling

# Use descriptive names def on_button_click(): print("Clicked") def on_entry_change(event): print(event.widget.get()) button.bind("<Button-1>", on_button_click)

Consistent Styling

# Define style constants PRIMARY = "primary" SUCCESS = "success" ERROR = "danger" btn = ttk.Button( ..., bootstyle=PRIMARY)

Frequently Asked Questions

What is TTKBootstrap and why should I use it?
TTKBootstrap is a modern theming library for Python's Tkinter that brings Bootstrap-inspired styling to your GUI applications. It eliminates the need to manually style widgets, making your applications look professional instantly. Use it when you want to create beautiful desktop applications without spending time on styling or design.
Can I change themes at runtime?
Yes! TTKBootstrap allows you to switch themes dynamically using root.style.theme_use(theme_name). This is perfect for giving users theme preferences or creating a theme selector in your application.
How many themes does TTKBootstrap offer?
TTKBootstrap comes with 5 main themes: Darkly (dark theme for reduced eye strain), Superhero (professional dark blue), Flatly (clean light design), Minty (fresh green), and Pulse (vibrant purple). Each is optimized for specific use cases.
Is TTKBootstrap free?
Yes! TTKBootstrap is completely free and open-source. You can use it in personal and commercial projects without any restrictions or licensing fees.
What are the system requirements?
TTKBootstrap requires Python 3.6 or higher and Tkinter (which comes with most Python installations). It works on Windows, macOS, and Linux.
Can I customize themes to match my brand?
Yes! You can customize colors and styles using TTKBootstrap's styling API. You can modify existing themes or create your own custom theme to match your brand colors and design preferences.
Where can I get help if I have questions?
TTKBootstrap has comprehensive documentation at ttkbootstrap.readthedocs.io, an active GitHub repository with examples and issues, and a helpful community of developers ready to assist.
